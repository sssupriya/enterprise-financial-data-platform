## Data Pipelines

1. A data pipeline moves data from a source to a destination.
2. ETL transforms data before loading it into the destination.
3. ELT loads raw data first and transforms it later.
4. Data quality checks are an important part of a pipeline.
5. Modern data engineering often separates ingestion,
   storage and transformation.
